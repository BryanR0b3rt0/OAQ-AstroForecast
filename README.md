\# OAQ-AstroForecast



Sistema de predicción de observabilidad astronómica para el Observatorio Astronómico de Quito.



\## Objetivos



\- Integrar datos meteorológicos locales.

\- Incorporar información satelital GOES.

\- Construir modelos predictivos de observabilidad astronómica.

\- Desarrollar una herramienta operativa para planificación de observaciones.



\## Estado



Fase 1: Exploración y caracterización de datos meteorológicos.
